# ChessArena

ChessArena is the first milestone of a real-time multiplayer chess platform.

## Milestone 1

Current features:
- React + TypeScript + Vite
- Playable local chess
- Legal moves via chess.js
- Check/checkmate/draw detection
- Responsive board
- New Game button

## Run locally

Install Node.js (LTS), then open this folder in a terminal:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:

http://localhost:5173
